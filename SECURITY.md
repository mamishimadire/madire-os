# Security policy

## Supported versions

Only the latest tagged release (the newest `vX.Y` or `vX.Y.Z` tag) receives security fixes. Older tags and unreleased branches are not supported.

## Reporting a vulnerability

Report vulnerabilities **only through GitHub's private vulnerability reporting**: open the repository's **Security** tab and choose **"Report a vulnerability"**.

Please don't report vulnerabilities in public issues, pull requests or discussions. Include the affected version (tag or commit), how to reproduce the problem and its effect.
